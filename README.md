# OldMap_OldStory — 시공간 싱크 (Time-Space Sync)

조선의 지도를 지금의 서울 지도 위에 겹쳐 보면서, 걸으며 현재의 위치를 과거와 겹쳐 볼 수 있는 모바일 웹 지도입니다.

## 데이터 출처

### 옛 지도
- **수선전도(서울전도, 首善全圖)**: 국립중앙박물관 소장 (소장품번호 남산 1304)
  - 공공누리 제1유형(출처표시)
  - 원본 이미지를 지오레퍼런싱해서 지도 타일로 가공해 사용합니다.

### 현대 지도
- **© OpenStreetMap contributors**
  - 라이선스: [ODbL](https://www.openstreetmap.org/copyright)
  - OpenStreetMap 데이터를 QGIS로 내려받아 직접 렌더링한 타일입니다. 외부 지도 서비스는 사용하지 않습니다.
